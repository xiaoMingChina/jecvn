**版本：2.0.0-fix · 发布日期：2026-09-25。** JevCN 仍是中文开发者社区；这次升级让可运行实验和可检验的工程模式成为站点的另一条主线。

## Playground 与 Labs 分工

[Playground](/playground/) 用于体验 `State → Choice / Noul / Score → Typed Decision + Probability`。 [Labs](/labs/) 研究原子决策进入游戏、故事或软件循环后的行为。目前收录俄罗斯方块公开项目、互动小说原型和中文分流实践。

互动小说可以在[规则演示](/playground/novel/)中免费推进，也可填写个人 Key 使用真实 Jev。真实模式每回合并发请求 Choice 与 Score；固定剧本负责台词，状态机负责阶段变化。示意模式不会冒充模型结果。

## Patterns 与证据

[Patterns](/patterns/) 提供 Router、Guard、Scorer、Judge、Fast Loop 等设计描述，并标出“待验证假设”或“实验中”。它们不是默认成立的最佳实践。Lab 元数据记录假设、设置、数据、结果、失败案例、延迟、成本、局限和结论；尚未测量的项目明确标为未知。

首页新增精选 Labs、Patterns 和一项标注为教学示意的概率分布。它不是实时 API 记录或 benchmark。现有学习文档、中文分流数据、生态资料、Playground 与 Worker 接口继续保留；旧 URL 维持兼容。

## 下一步

继续以真实运行记录、失败样例和成本/延迟测量更新实验状态。欢迎通过 [GitHub Issues](https://github.com/xiaoMingChina/jevcn/issues) 提交 Lab、项目、复现结果或中文内容。
