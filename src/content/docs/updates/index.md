## 状态怎么读

- **来源已核查：** 已阅读原始资料，确认描述有据可查；不代表已安装或实测。
- **基线已复现：** 已运行文章明确指定的本地基线，保留样例、脚本和输出；不等于模型已测。
- **模型已复现：** 仅在保留真实请求结果、版本与运行条件后使用。目前首篇实践尚未达到此状态。
- **需要更新：** 已知版本变化、断链或结论不再适用时标注，并说明原因。
