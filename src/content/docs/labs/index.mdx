# 开放实验室

Playground 观察原子能力如何给出类型化决策；Labs 探索这些决策进入完整软件之后会发生什么。我们不预设 Jev 优于规则、传统算法或 LLM，公开记录方法、失败与限制。

<RegistryCards kind="labs" />

新增实验只需补充 [`src/data/labs.mjs`](https://github.com/xiaoMingChina/jevcn/blob/main/src/data/labs.mjs) 元数据和对应内容页。类别先服务有内容的实验，不创建空白占位页。
