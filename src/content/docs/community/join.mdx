欢迎来到 JevCN！这里由关注 Jev 的中文开发者共同维护，专注极致轻量、低延迟的概率语义决策引擎落地。我们希望把入门文档、可复现的实验与真实工程经验连接起来，让你能从一个小场景开始，逐步理解决策模型的能力与边界。

无论你正在尝试第一个 SDK 示例，还是构建智能体、SaaS 或客户服务系统，都欢迎分享问题、测量结果与实践心得。交流时请尊重彼此，注意去除 API 密钥、客户信息和其他敏感数据。

## 问题反馈与常见疑问

### 文档有错误，在哪里反馈？

请在 [GitHub Issues](https://github.com/xiaoMingChina/jevcn/issues) 中先搜索已有反馈，再创建问题。附上页面地址、预期结果和实际结果；涉及 SDK 时，请补充版本与最小复现示例。

### 可以提交自己的项目吗？

欢迎！请提供项目链接、适用场景、运行步骤与已知限制，并参照[全球开源项目收录](/ecosystem/showcase/)提交贡献。性能结论请注明测试条件。

### 这里是 Jev 官方支持渠道吗？

JevCN 由中文开发者发起并独立维护，参考 [TypeSafe AI 官方资料](https://typesafe.ai/)，关注 Jev 的技术演进，专注于低延迟智能体与概率语义决策在中文业务场景中的落地。本站不是 TypeSafe AI 官方站点，也不代表官方提供服务承诺。

账号、计费与产品服务问题请通过 [Jev 官方网站](https://typesafe.ai)查找支持入口。
